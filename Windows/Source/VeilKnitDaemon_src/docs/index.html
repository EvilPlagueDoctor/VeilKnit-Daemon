Crate daemon_network_sdk

WindowsProtocol 2High-level SDK for the Daemon Network local application API.

Applications work with users, messages, subscriptions, and request/response conversations. The SDK hides named pipes, credential files, challenge-response proofs, session tokens, direct handshakes, and offline mailbox fallback.

Start here: most applications need only NetworkApp::connect, NetworkIdentity, NetworkApp::send, and NetworkApp::subscribe. See the complete tutorial.

Quick example

use daemon_network_sdk::{ClientError, NetworkApp};

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    let app = match NetworkApp::builder("example.hello")
        .display_name("Hello Network")
        .connect()
        .await
    {
        Ok(app) => app,
        Err(ClientError::AuthorizationRequired(request)) => {
            println!("Approve with: {}", request.approval_command());
            request.wait().await?
        }
        Err(error) => return Err(error.into()),
    };

    println!("Connected as {}", app.local_user().identity);
    Ok(())
}

Design guarantees

App isolation

The daemon authenticates each app ID and filters incoming plaintext so one app cannot read another app's messages.

Transport independence

send may use an established encrypted handshake or the mailbox fallback. App code does not choose or inspect the transport.

User approval

Missing credentials create a pending authorization request. The local daemon user must approve it before a credential is issued.

Opaque identities

NetworkIdentity carries the shareable network address without requiring applications to manipulate raw DHT APIs.

Struct NetworkApp

The main authenticated application handle. Clone it freely to share it among Tokio tasks.

async fn NetworkApp::connect(app_id: impl Into<String>) -> Result<NetworkApp, ClientError>
Discovers a credential and endpoint, authenticates, and reads the local user identity. On first run, returns ClientError::AuthorizationRequired.
fn NetworkApp::builder(app_id) -> NetworkAppBuilder
Use the builder to set a friendly display name, custom non-administrative capabilities, an explicit endpoint, or a credential path.
fn local_user(&self) -> &LocalUser
Returns the daemon username and this user's NetworkIdentity.
async fn send(&self, recipient: &NetworkIdentity, payload: impl AsRef<[u8]>) -> Result<MessageReceipt, ClientError>
Queues one application payload. The daemon first attempts live encrypted delivery and falls back to offline mailbox delivery when needed.
async fn send_text(&self, recipient: &NetworkIdentity, text: impl AsRef<str>) -> Result<MessageReceipt, ClientError>
Convenience wrapper for UTF-8 text.
async fn send_with_options(&self, recipient, payload, options: MessageOptions) -> Result<MessageReceipt, ClientError>
Sets a conversation ID, expiration timestamp, or response expectation.
async fn broadcast(&self, recipients, payload) -> Vec<BroadcastDelivery>
Sends the same payload to multiple identities with bounded concurrency and returns one result per recipient.
async fn request(&self, recipient, payload) -> Result<RequestReceipt, ClientError>
Creates a random 32-byte conversation ID and marks the message as awaiting a response.
async fn respond(&self, request: &IncomingMessage, payload) -> Result<MessageReceipt, ClientError>
Replies to the sender while preserving the request's conversation ID.
async fn subscribe(&self) -> Result<MessageStream, ClientError>
Opens the app-filtered stream. It receives queued daemon inbox messages first, then live messages.
async fn retrieve_mail(&self) -> Result<(), ClientError>
Requests an immediate mailbox scan instead of waiting for periodic retrieval.
async fn mailbox_status(&self) -> Result<MailboxStatus, ClientError>
Returns mailbox DHT addresses, queue counts, key epoch, and known custodian count.
async fn status(&self) -> Result<serde_json::Value, ClientError>
Reads the daemon's current structured network status.
async fn events(&self) -> Result<NetworkEventStream, ClientError>
Subscribes to structured daemon events when the app has SubscribeNetworkStatus.

Structs MessageReceipt, RequestReceipt, and BroadcastDelivery

Receipts mean the daemon accepted work; they do not prove the remote application displayed or acknowledged the payload.

Struct MailboxStatus

Contains mailbox_dht, mail_send_dht, mail_response_dht, receive_key_epoch, pending page sets, outgoing count, awaiting-response count, and known custodian count.

Enum ClientError

Enum AppCapability

The default high-level connection requests messaging, receiving, public-profile reads, and network status. Administrative capabilities are never granted through first-run app authorization.

Module advanced

Re-exports NetworkApiClient, CredentialFile, raw message subscriptions, and session structures. Use it only when a daemon protocol operation has not yet been wrapped by NetworkApp.

Current scope: a global username search or peer-directory API is not exposed yet. Applications exchange NetworkIdentity values explicitly, such as through room keys, QR codes, contacts, or invitation messages.
